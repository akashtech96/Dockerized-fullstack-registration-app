# Docker Assignment

## Project Overview

This project demonstrates a Dockerized Full Stack Application.

## Technologies Used

- Docker
- Docker Compose
- Flask
- Express.js
- MongoDB Atlas
- Python
- Node.js

## Project Structure

```
Docker_Assignment
│
├── backend
├── frontend
└── docker-compose.yml
```

## How to Run

```bash
docker compose up --build
```

Open:

```
http://localhost:3000
```
